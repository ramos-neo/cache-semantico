Cenários

Roteiro didático alinhado a test.http: AI → exact → semantic → AI. Cada passo de analyze valida o campo source esperado.

Pré-requisitos

  • API em localhost:8000 (npm run dev)
  • Postgres + pgvector no ar (docker compose -f docker/docker-compose.yml up -d)
  • GEMINI_API_KEY configurada no .env
  • Rode a sequência completa sem reiniciar a API (o cache exact é só em memória)
  • Idealmente tabela ai_response_cache vazia (ou sem itens muito parecidos com “cancelar meu plano”); o passo 1 grava o seed semântico
